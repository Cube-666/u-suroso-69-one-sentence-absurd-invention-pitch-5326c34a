A showerhead that negotiates a formal ceasefire with the toilet so nobody flushes while you are mid-shampoo. One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: the shower that turns scalding or freezing the moment someone flushes.

The program writes the pitch to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and checks it first: one sentence, 1–220 characters, UTF-8, not only white space. No network, no randomness, Node standard library only.

## Run it

```sh
node main.ts
```
